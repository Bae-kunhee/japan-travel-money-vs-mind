# 방법론 상세

## 1. 왜 일본 데이터만으로는 안 되나

2022~2024년 엔저 시기는 코로나 이후 여행 회복기(보복 여행)와 겹쳐요. 일본 방문객 수를 환율로만 회귀하면 회복 효과까지 환율 계수가 흡수해서 엔저 효과가 부풀려져요(누락변수 편향). 그래서 같은 시기 엔저가 없었던 베트남·태국·필리핀·대만을 비교국으로 함께 봐요.

## 2. 분석 방법의 성격

이 연구는 **이원 고정효과 패널 회귀 + 분포시차 모형**이에요. ARIMA 같은 예측용 시계열 모형도, 단순한 평균 비교 가설검정도 아니에요. 계수(θ, γ)를 먼저 추정하고, 그 계수에 대해 가설검정과 신뢰구간을 구하는 구조예요. 시계열 요소는 다음 네 군데에 들어가요.

- 환율의 시차 효과(분포시차, 0~10개월)
- 사전 진단(단위근, 공적분)
- 자기상관과 국가 간 상관에 강건한 표준오차(Newey-West, Driscoll-Kraay)
- 강건성 확인용 전년동월비 모형

## 3. 모형

### 모형 1: 일본 단독 (통념 재현)

```
ln V_t = α + Σ_{k=0}^{K} β_k ln FX_{t−k} + γ·불매_t + 월 더미 + ε_t
```

- 표본: 일본, 2016.01~2025.12 중 봉쇄 기간 제외 (n = 89)
- K는 AIC와 BIC 선택값 중 작은 값 (K = 0). 비교용으로 K = 10도 함께 보고
- 표준오차: Newey-West (bandwidth = ⌊4(T/100)^{2/9}⌋)
- 진단 결과 비정상, 공적분 없음, 잔차 자기상관이 확인되어 **신뢰구간은 믿지 않고**, 부풀려진 크기를 보여주는 용도로만 써요.

### 모형 2: 5개국 패널 (본 분석)

```
ln V_ct = Σ_{k=0}^{10} β_k ln FX_{c,t−k} + γ·불매_ct + μ_{c,m} + λ_t + ρ_{e(c,t)} + ε_ct
```

| 항 | 의미 | 흡수하는 것 |
|---|---|---|
| μ_{c,m} | 국가 × 달력 월 고정효과 (60개) | 나라별 인기도와 성수기 모양 |
| λ_t | 연-월 고정효과 | 같은 달 모든 나라에 공통인 충격: 코로나, 유가, 소득, 원화 전반의 강약, 해외여행 수요 전반 |
| ρ_e | 재개 후 경과 개월 고정효과 (0~17, 18+) | 보복 여행 회복 곡선. 나라마다 재개 시점이 달라 λ_t만으로는 못 잡는 부분 |
| θ = Σβ_k | **돈** | 누적 환율 탄력성 |
| γ | **마음** | 불매운동 효과 (일본, 2019.7~2020.2) |

- 표본: 5개국, 봉쇄 기간 제외, n = 463
- K = 10은 K = 0~12 중 AIC 최소값
- 경과 개월 18+ 구간은 연-월 고정효과와 완전 공선이라 자동으로 빠지고, 장기 수준으로 정규화돼요. 기준은 코로나 이전.
- 표준오차: **Driscoll-Kraay** (`linearmodels.PanelOLS`, Bartlett 커널, bandwidth = ⌊4(T/100)^{2/9}⌋). 국가 간 같은 달 상관과 시계열 자기상관에 모두 강건해요.
- 개별 β_k는 서로 공선성이 커서 흔들려요. 그래서 "몇 개월 뒤에 효과가 나타나는지"는 특정하지 않고, 합 θ만 해석해요. K를 0~12로 바꿔도 θ는 −0.87 ~ −1.17 범위예요 (`results/lag_sensitivity.csv`).

## 4. 돈 vs 마음

- **크기 비교**: γ를 "엔화 10% 하락 효과(θ · ln 0.9)"의 몇 배인지로 표현 → 불매운동은 약 11배
- **손익분기 엔저 폭** d\*: θ · ln(1 − d\*) = −γ → d\* = 1 − exp(γ/θ)
  - 비율 추정량이라 분포가 비대칭이에요. 신뢰구간은 (θ, γ)의 결합 정규분포에서 20만 번 뽑는 모의실험으로 구하고 (seed 0), 델타 방법 결과도 같이 저장해요.
  - 결과: 약 69% (모의실험 95% CI 47~92%). 불매 정점 기준 약 80%
  - 강건성: 시차 K, 비교국 제외, 달력 월 고정효과, 2020년 1~2월 제외 등으로 바꾸면 48~87%
- **같은 시기 분해**: 2019년 하반기 일본 감소(−55%)를 돈 몫(엔화 약 6% 강세 → −5)과 마음 몫(불매 → −105, 로그×100)으로 나눠요.
- **다른 이슈와 비교**: 후쿠시마 오염수 방류(2023.9~) 더미를 넣으면 −13 ~ −18%이고 유의하지 않아요.
- **통념 모형이라면**: 모형 1 계수로 같은 계산을 하면 손익분기가 21%로 나와요. 엔저 효과를 부풀리면 "돈이 마음을 쉽게 이긴다"고 오판하게 돼요.

## 5. 수요 이동 (2019년 불매)

목적지별로 한국인 전체 출국자 대비 비중을 반기별로 구해요.

```
did = [비중(2019H2) − 비중(2018H2)] − [비중(2019H1) − 비중(2018H1)]
```

상반기(불매 전) 변화를 빼서 원래 추세를 제거한 값이에요. 사람 수 기준으로도 같은 차이를 계산해요. 일본은 약 −165만 명이고, 증가한 목적지의 합은 약 70만 명(약 42%)이에요. 목적지별 통계에 중국이 빠져 있어 이동 비율은 실제보다 작게 잡혔을 수 있어요.

## 6. 엔저 폭별 효과 (이슈 없는 기간)

- 표본: 모형 2 표본에서 불매 기간 제외 (n = 455)
- 엔저 수준: 통화 가치 로그의 10개월 평균(시차 0~10)에서 자국 2018년 평균을 뺀 값
- 세 가지 방식으로 추정해요.
  1. 선형: 일정 탄력성 −1.08 (10% 엔저 → +12%, 95% CI +7 ~ +17%)
  2. 구간 더미: 10% 이상 비쌈 / 5~10% 비쌈 / **0~5% 비쌈(기준)** / 0~5% 쌈 / 5% 이상 쌈
  3. 구간별 선형: −5% 지점에서 기울기가 꺾이는지 검정 (z = 1.72, p ≈ 0.09), 엔저와 엔고의 비대칭 검정 (z = −0.72)
- 5% 이상 엔저 구간은 일본 2024~25년 25개월에서만 관측돼서 "시사" 수준으로만 해석해요.

## 9. 2018 → 2024~25 일본 증가분 분해

같은 달끼리 비교한 로그 차이(×100)를 모형 2의 항으로 나눠요.

- 실제 증가: +19.2 (약 +21%)
- 공통 요인(연-월 + 경과 개월 고정효과): +18.0
- 엔저: θ × (시차 창 평균 엔화 변화 −7.9%) = +7.4 → 증가분의 약 40%
- 일본 고유 요인(나머지): −6.3
- 통념 모형이라면 엔저 몫이 +22로 증가분 전부를 설명하는 것처럼 보여요.
