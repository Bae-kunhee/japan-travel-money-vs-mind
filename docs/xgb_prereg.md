# XGBoost 강건성 점검: 사전 명시 (결과 확인 전 작성, 2026-10-29)

## 질문
선형 패널 모형(Model 2)의 함수 형태 가정(일정 탄력성, 가산적 불매 효과)이 틀렸다면 결론이 바뀌는가?

## 설계
1. **식별은 그대로, 함수 형태만 유연하게.** Model 2와 같은 고정효과(국가×달력월, 연-월, 재개 후 경과 개월 구간)를
   y(ln 방문객)와 설명변수(ln 환율 시차 0~10, 불매) 각각에서 회귀로 제거(Frisch-Waugh-Lovell)한 뒤,
   잔차끼리 (a) OLS, (b) XGBoost 를 적합한다. (a)는 Model 2와 수치적으로 같다(θ −0.910, γ −1.053 확인).
2. **XGBoost 설정 (고정):** max_depth 2, n_estimators 400, learning_rate 0.03, subsample 0.8,
   colsample_bytree 0.8, min_child_weight 3, reg_lambda 1, seed 2026. 민감도: max_depth 3, 4.
3. **표본 밖 비교: rolling origin.** 기준 시점 2018-06부터 2025-06까지 6개월 간격, 매번 과거 자료로만 학습하고
   다음 6개월의 일본 방문객을 예측. 해당 달의 공통 수요(연-월 효과)는 같은 달 비교국 4개국 자료로만 추정
   (일본의 그 달 값은 쓰지 않음). 두 모형은 같은 분할, 같은 고정효과 추정치를 공유한다.
4. **효과 크기: 반사실 예측.**
   - 10% 엔저: 환율 시차 11개 잔차를 모두 같은 폭으로 옮겨 총 ln 0.9 만큼 바꾼다. 트리의 외삽 문제를 줄이기 위해
     중앙 차분(−0.0527 / +0.0527)으로 계산하고, 두 지점이 모두 학습 범위(1~99 백분위) 안인 관측치만 평균한다.
   - 불매: 일본 불매 관측치(2019-07~2020-02, 8개월)에서 불매 잔차를 1만큼 낮춘 예측과의 평균 차이.
   - 비율 = 불매 효과 / 10% 엔저 효과. 시간 블록(12개월) 부트스트랩 300회로 95% 구간.
5. **SHAP:** 환율 시차 11개의 SHAP 합을 환율 잔차에 대해 그려 선형성(일정 탄력성) 점검. 효과 크기 산출에는 쓰지 않음.

## 판정 기준 (결과 전 고정)
- **기준 1 (적합도):** rolling origin 표본 밖 RMSE에서 XGBoost가 선형 모형보다 의미 있게 낫지 않으면
  (Diebold-Mariano 검정, 5%), 선형 모형으로 충분하다고 본다.
- **기준 2 (결론):** XGBoost의 "불매 ÷ 10% 엔저" 비율이 선형 모형의 신뢰구간 6~24배 안에 들면 결론이 유지된다고 본다.
- **하지 않는 것:** 손익분기 엔저 폭(69%)은 XGBoost로 다시 계산하지 않는다. 관측된 최대 엔저(약 12%)를 넘는
  외삽이라 트리 모형으로는 의미가 없다.

## 추가 (2026-10-30, 결과 확인 후): 기준 2를 보고에서 뺀 경위

- 기준 2의 사전 계산 방식은 4.8배로 미충족이었어요. 원인은 0/1 불매 변수에서 고정효과를 빼면 불매 달 값이 0.68로 남고, 불매를 끄는 반사실(−0.32)이 트리가 본 적 없는 값이라는 점이었어요. 사후에 imputation 추정(불매 없는 달로만 학습)으로 바꾸면 8.7배(블록 부트스트랩 6.6~19.2배)였어요.
- 그런데 imputation도 외삽을 피하지 못했어요. 불매 달은 고정효과를 뺀 환율 잔차 분포의 끝(시차 합 기준 99~100 백분위)에 있고, 불매 달 × 시차 11개 조합의 36%가 학습 범위(1~99 백분위) 밖이에요. 트리는 이 구간에서 평평해져서 반사실 예측을 믿기 어렵고, 정답이 없어 확인할 수도 없어요.
- 대안으로 자연 3차 스플라인(범위 밖에서 직선으로 이어짐)을 사전 명시하고([`docs/spline_prereg.md`](spline_prereg.md), `src/spline_check.py`) 돌렸지만, 주 지표(11개월 단순 평균 지수)가 매듭 수에 따라 흔들려(4.7~10.9배, 매듭 5개에서 비선형 Wald p < 0.001) 사전 대체 조건을 충족하지 못했어요. 모형 2 가중치 지수(보조)는 10.3배(6.1~19.0)로 통과했지만, 결과를 보고 주 지표를 바꾸는 것은 하지 않았어요.
- 그래서 보고서에는 정답으로 채점되는 기준 1(표본 밖 예측 비교)만 남기고, 효과 크기는 XGBoost로 보고하지 않아요. 결론의 범위(약 9~11배)는 모형 2, 불매 스톡, BIC 시차, 비교국 8개국 결과로 유지돼요.
- 계산 결과는 모두 `results/xgb_robustness.json`에 그대로 남겨 두었어요.
