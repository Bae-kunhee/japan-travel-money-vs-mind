# 자연 3차 스플라인 선형성 점검: 사전 명시 (결과 확인 전 작성, 2026-10-29 22:50 KST)

## 질문
모형 2의 "일정 탄력성" 가정이 틀렸다면 결론(불매 ÷ 10% 엔저 ≈ 11배)이 바뀌는가?
XGBoost 점검은 불매 달이 환율 분포의 끝(99~100 백분위)에 있어 트리의 외삽 한계에 걸렸다.
범위 안에서는 휘고 범위 밖에서는 직선으로 이어지는 자연 3차 스플라인으로 같은 질문을 다시 푼다.

## 설계
1. 환율 지수 (11개 시차를 하나로)
   - A (주): Z_ct = 시차 0~10 ln FX의 단순 평균 − 그 나라 2018년 ln FX 평균
   - B (보조): I_ct = Σ w_k ln FX_{c,t−k}, w_k = β_k/θ (모형 2 추정치) − 그 나라 2018년 평균
2. 모형: ln V_ct = s(지수) + γ·불매 + 모형 2의 고정효과 전부 (국가×달력 월, 연-월, 재개 후 경과 개월). Driscoll-Kraay SE.
   s = 자연 3차 스플라인 (양 끝 매듭 밖은 직선). 매듭 4개, 불매 아닌 관측치 지수의 5·35·65·95 백분위 (Harrell).
   민감도: 매듭 3개 (10·50·90), 5개 (5·27.5·50·72.5·95).
3. 효과
   - 10% 엔저: 각 관측치에서 지수를 ln 0.9/2씩 양쪽으로 옮긴 차이의 평균 (두 점 모두 경계 매듭 안인 관측치만).
   - 불매: (주) 같은 모형의 γ. (보조) imputation: 불매 아닌 달로만 적합하고 불매 달의 불매 없는 값을 예측.
   - 비율 = 불매 ÷ 10% 엔저. 주 추정은 계수 분포(DK 공분산) 모의실험 10,000회, imputation은 12개월 블록 부트스트랩 300회.
4. 표본 밖: XGBoost와 같은 rolling origin (2018.6~2025.6, 6개월 간격, 일본 다음 6개월).
   선형 지수 모형 vs 스플라인 지수 모형, Diebold-Mariano.

## 판정 기준 (결과 전 고정)
- 기준 1 (선형성): A의 비선형 스플라인 항이 모두 0이라는 Wald 검정(DK)을 5%에서 기각하지 못하고,
  표본 밖에서 스플라인이 선형보다 유의하게 낫지 않으면(DM 5%) 일정 탄력성 가정으로 충분하다고 본다.
- 기준 2 (결론): A의 주 추정 비율이 본 모형의 모의실험 95% 구간 6~24배 안이면 결론이 유지된다고 본다.
- 대체 조건: 기준 1, 2의 판정이 매듭 수 민감도와 B에서도 같은 방향이면 XGBoost 점검을 이 분석으로 대체한다.
- 하지 않는 것: 손익분기 69%는 스플라인으로도 다시 계산하지 않는다 (관측 범위의 약 6배 외삽).
