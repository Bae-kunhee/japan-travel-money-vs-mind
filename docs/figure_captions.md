# 그림 캡션·각주 초안

그림 안에는 제목·부제·출처를 넣지 않았다. 제출 양식의 그림 번호, 이름, 각주에는 아래 문장을 쓴다.
그림 안에는 표시가 무엇을 뜻하는지 알려 주는 라벨만 남겼다.
색은 역할을 고정했다. 환율·엔저는 파랑, 불매는 주황, 비교국·공통 요인은 회색, 일본 실측은 검정이다.
