## 가공 자료 (`processed/panel.csv`)

`src/build_panel.py`가 만드는 국가 × 월 패널이에요. 주요 변수:

| 변수 | 정의 |
|---|---|
| `country` | JP, VN, TH, PH, TW |
| `t` | 월 번호, 2015-01 = 0 |
| `visitors`, `ln_v` | 한국인 방문자 수와 그 로그. 1명 이하(봉쇄 기간 0 또는 0.01 표기)는 결측 처리 |
| `fx`, `ln_fx` | 해당 통화 1단위(엔·동은 100단위)당 원화, 월평균. **값이 작을수록 그 나라 통화가 싸다** |
| `ln_fx_l1..l12`, `ln_fx_f1..f3` | 환율 시차(1~12개월 전)와 선행값(위약 검정용) |
| `closed` | 봉쇄 기간 (2020.03 ~ 재개 직전). 분석에서 제외 |
| `event` | 입국 재개 후 경과 개월 (재개 월 = 0). 재개 전은 결측 |
| `boycott` | 일본 2019.07 ~ 2020.02 = 1 |
| `idx_2018` | 2018년 같은 달 = 100인 방문자 지수 (2019년은 불매운동으로 눌려 있어 기준 연도는 2018) |
| `fx_idx_2018` | 2018년 평균 = 100인 환율 지수 |
| `*_alt` | 재개 시점을 목적지 기준으로만 정한 대안 변수 (강건성 검정용) |
